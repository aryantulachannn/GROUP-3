EDUMARTH CONNECTED PROJECT — MAC APPLE SILICON

QUICK START
1. Extract this ZIP. Keep your previous project as a backup.
2. Open Terminal. Type cd followed by a space, drag this extracted project folder
   into Terminal, and press Enter.
3. Run these commands one at a time:

   cd backend
   npm ci
   npm start

4. Open Safari: http://127.0.0.1:3001
5. Leave Terminal running while using the website.
6. Stop with Control+C when finished.

Requires Node.js 24 or later. Your existing Node.js 24.22.1 is suitable.
If port 3001 is already being used, stop the old server in its Terminal tab with
Control+C. Alternatively run PORT=3002 npm start, then open the URL it prints.
Open the website through this server, rather than double-clicking index.html.
Both server.js and the old api-server.js command now start this same application.
The homepage is now the website, replacing the old backend welcome message.

WHAT IS CONNECTED
- All 20 products are loaded from edumarth.db through GET /api/products.
- Search, categories, price filters, sorting, product details and browser cart remain.
- About Us and Contact pages keep your supplied design and logo.
- Both the Contact page and homepage pop-up submit to POST /api/enquiries.
- Browser validation and independent server validation check submitted fields.
- Success appears only after SQLite confirms the enquiry was saved.
- Each saved enquiry has a reference number. No email notification is configured.
- A submission key prevents duplicate records when the same submission is retried.
- The cart is still browser-local. There are no payments or orders.

VIEW A SAVED ENQUIRY
1. Open this extracted project's edumarth.db using DB Browser for SQLite.
2. Open Browse Data and select enquiries.
3. Submit a test message using the website; use fictional contact details.
4. Refresh/reopen the database view to see the new row.
5. New submissions have is_demo=0. The original three sample rows have is_demo=1.

DATABASE DETAILS
Original product records and sample enquiries were preserved. On first startup,
the server adds an optional request_key column and unique index to enquiries to
support duplicate-submission protection. No existing rows are deleted.
The server enables foreign keys and uses parameterised enquiry inserts.
The product API maps database names such as product_id and price_cents to frontend
names such as id and price. Prices remain integer AUD cents, not floating point.
Some product feature lists in your supplied database are empty; these are preserved.

API ROUTES
GET  /api/health      Status and product count
GET  /api/products    Product records in frontend-compatible format
GET  /api/categories Category IDs and labels
POST /api/enquiries  JSON name, email, topic, subject, message;
                     requires an Idempotency-Key header (generated by the form)
Enquiries have no public read/list route. View them directly in DB Browser locally.
The server serves only approved public files and assets; it does not serve the
SQLite database, dependency folders, original data file or backend source.

TESTING
From backend, run npm test after npm ci. Tests use a temporary database copy and
leave your supplied database untouched. They exercise product/category APIs,
page/asset delivery, valid persistence, invalid inputs, malformed and oversized
JSON, cross-origin rejection, safe SQL values, duplicate retry protection, persistence
after restart and blocked database/source-file URLs.
JavaScript syntax and HTML asset/section links were also checked.
Visual browser testing was not completed here. Check the layout and both contact
forms in Safari and on a phone before publishing or submitting the assessment.

HOSTING / SCOPE
This runs locally on your Mac, bound to 127.0.0.1. It is a capstone development
project. GitHub Pages alone cannot run the Node.js server or save SQLite enquiries.
A public deployment requires separate backend hosting, HTTPS, durable database
storage/backups, spam controls and appropriate privacy handling.
Do not publish real enquiry records, databases or credentials in a public repository.
No credentials or email service are included.
